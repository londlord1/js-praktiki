ПР15 — Set, Map и Array

Задания для самостоятельного выполнения. Работа с Set, Map, WeakMap, WeakSet и конвертация между структурами.

Задание 1: Автодополнение тегов

Выпадающий список с подсказками при вводе тега. Подсказки берутся из массива allTagsEver и фильтруются через filter, уже добавленные исключаются.

Статей сохранено: 0. Всего уникальных тегов: 0.

Задание 2: Инверсия статистики — статьи по тегу

Map, где ключ — тег, а значение — Set из ID статей. Позволяет быстро находить статьи с конкретным тегом.

Нажмите кнопку после сохранения статей.

Задание 3: Поиск пересечения тегов

Функция находит теги, общие для двух Set (статей), через фильтрацию: [...setA].filter(tag => setB.has(tag)).

Введите теги через пробел и нажмите кнопку.

Задание 4: WeakMap и WeakSet (кэш)

Кэш вычислений для объектов статей через WeakMap: ключ — объект, значение — подсчитанное число тегов. Когда объект теряет ссылки, запись удаляется.

Нажмите кнопку, чтобы закэшировать вычисление.
