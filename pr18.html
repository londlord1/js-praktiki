Расширение, которое привязывает заметку к URL каждой вкладки и восстанавливает её при повторном открытии (имитация browser.storage.local с ключом по URL).

Выберите вкладку и сохраните заметку — она привяжется к URL.

Справка: manifest.json (контент-скрипт, задание 6)

{
  "manifest_version": 2,
  "name": "Hi Student",
  "version": "1.0",
  "browser_action": { "default_popup": "popup/popup.html" },
  "permissions": ["activeTab", "storage"],
  "content_scripts": [
    { "matches": ["<all_urls>"], "js": ["content-script.js"] }
  ]
}
